# Runbooks

Runbooks describe repeatable procedures that an operator or agent can follow safely.

Good runbooks include:

- Purpose
- Preconditions
- Commands
- Expected output
- Rollback or cleanup steps
- Verification

Add project runbooks when deployment and operations work begins in later milestones.
