# Documentation

This directory is the current project knowledge base.

## Sections

- `adr/` — architecture decision records
- `PLAN.md` — canonical implementation roadmap and milestone checklist
- `plans/` — executable milestone plans and completed checkpoints
- `performance/` — measured load results, host specifications, and limitations
- `reference/` — stable technical references
- `research/` — exploratory notes, comparisons, and findings
- `runbooks/` — repeatable operational procedures
- `security/` — threat models, ceremonies, recovery rules, and independent-review gates
- `reviews/` — repository and roadmap completion audits
- `labels.md` — Open Pilot label lifecycle
- `open-pilot.md` — how to prepare issues for Open Pilot

Keep docs current, concise, and linked from this hub.
